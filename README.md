# 避けろ！ヘーベルハウス君！

落ちてくる敵を避けて、ハイスコアを目指そう！

**「避けろ！ヘーベルハウス君！」** は、プレイヤーを操作して敵を避け続けるシンプルなブラウザゲームです。

スコアが増えるほど敵のスピードも上がっていきます。敵の動きを見極めながら、できるだけ長く生き残ろう！

## 🎮 ゲームをプレイ

**[▶ ゲームを始める](https://lifons233879.github.io/hebel-haus-game/)**

ブラウザからアクセスするだけで遊べます。

## 🕹️ 遊び方

1. ゲーム画面で START ボタンをクリックするか、スペースキーを押してスタートします。
2. マウスを左右に動かして、プレイヤーを操作します。
3. 上から落ちてくる敵に当たらないように避けます。
4. 敵を1体避けるごとに10ポイント獲得できます。
5. スコアが増えるほど敵が速くなるので、注意しながらハイスコアを目指しましょう！

ゲームオーバーになったら、Rキーで再挑戦できます。

## ✨ ゲームの特徴

- **シンプルな操作** — マウスを左右に動かすだけでプレイできます。
- **3体の敵** — それぞれ異なる動きでプレイヤーに迫ります。
- **スコアシステム** — 敵を避けるたびにポイントを獲得できます。
- **難易度の変化** — スコアに応じて敵のスピードが上昇します。
- **ハイスコア保存** — これまでの最高得点をブラウザに保存します。
- **効果音** — ゲーム開始、得点獲得、ゲームオーバーなどの場面で音が鳴ります。
